### Computer Organization and Architecture Assignments for Semester 202505

#### Organizational Background
TAR Airline is a commercial airline company responsible for managing domestic and international flight operations. Traditionally, the airline has relied on manual processes that require passengers to physically visit the airport for ticket booking. Now, TAR Airline aims to modernize its systems to improve customer experience, reduce manual workload, and ensure timely access to information.
#### Problems with Current System
The booking process was highly inconvenient, as passengers were required to visit the airline office or airport in person just to reserve a seat. This also made check-in slow, with long queues forming at the airport. Additionally, there were no live flight updates, so travelers couldn’t easily check for delays, changes, or cancellations. Tickets added to the hassle, as everyone had to print physical copies of their tickets or boarding passes, making the entire experience inefficient and frustrating.
#### Proposed System
The proposed system is a command-line Flight Ticketing System developed in 32-bit Assembly Language. It allows TAR Airline staff to log in, book flights, select travel options, and process payments efficiently. Users can choose destinations, ticket classes, one-way or two-way trips, and optional insurance. The system captures passenger details, calculates the total price with any applicable member discount, and displays a digital receipt. It supports multiple bookings in a single session and replaces the old manual process
#### Advantages of Proposed System
This system improves booking speed, reduces human error, and enhances security through user login. It automatically calculates prices, discounts, and change using arithmetic operations. Membership is detected based on User ID, and the system applies a 15% discount automatically. Input validation ensures correct data entry, and the paperless process eliminates the need for printed tickets. Overall, it offers a faster, safer, and more organized way to manage flight bookings.
