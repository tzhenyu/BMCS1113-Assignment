System Proposal 
• Students to suggest command line interface application program / system that  includes arithmetic (mathematical calculations), comparison and logical  computations.  
• Your suggested system can be any Ticketing System, Ordering System, Enquiry  System and etc. The system should consist of different modules e.g. login  module, calculation module, summary module etc 
• Tutor will evaluate and approve the proposed system (to avoid duplicated titles) on Week 7. 
• Create a System Proposal that consists of the following topics eg. organizational  background, problems with current system, proposed system, advantages of  proposed system and follow with system flow charts.
Program Coding (80 marks) 
• Develop a 32-bit Assembly Language Program based on the System Proposal.  • Your program shall include, but not limited to, the following basic functionalities: (i) Perform user authentication (login)  
(ii) Display at least TWO (2) levels of menu option.  
(iii) Must involve the four main arithmetic calculations: ADD, SUB, MUL, DIV  
(iv) Perform input validation and provide proper guidelines  
(v) Provide options to allow the user to loop back the system  
(vi) Provide summary (eg. grand sum total, total items, total attempts etc)  on transactions done  
(vii) Final result must be presented in at least TWO decimal places. • Students are advised to use Microsoft Visual Studio and Irvine library to develop  your system.  
• Each member must work on different module(s). The individual work should  then be combined to produce a complete assembly language program. 
Final Submission (20 marks) 
• All deliverables such as program source code, program executable file and Final  Report

This assessment aims to evaluate students on CLO3:  
Produce the solution on programming problem by using assembly language skills. (P3, PLO3)
